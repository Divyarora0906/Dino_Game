# 🦕 Dino Runner — JavaScript Game

An **offline-style Dino Runner game inspired by the Chrome Dino** — built as a browser web app using **HTML, CSS & JavaScript**.  
Jump over obstacles, survive as long as you can, and chase a high score!

---

## 🚀 Features

### 🏃 Smooth Dino Jump & Gameplay
- Tap / Click / Press **Spacebar** to jump  
- Simple and responsive controls  
- Works on both **mobile & desktop**

---

### 🎯 Random Obstacle Spawning
- Dynamically generated obstacles  
- Random spawn timing for replayability  
- Collision detection using bounding boxes

---

### 🧮 Score & UI System
- Live **score counter**
- **Final score popup** on Game Over  
- **Restart & Quit buttons**
- Clean minimal UI (no heavy assets)

---

### ⏸ Auto Pause System
- Game **automatically pauses when you switch tabs / apps**
- Prevents unfair deaths
- Resumes when you return

---

### 📱 Mobile-Friendly Controls
- Touch to jump  
- Same smooth mechanics as keyboard
